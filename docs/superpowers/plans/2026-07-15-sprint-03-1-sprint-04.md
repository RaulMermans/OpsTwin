# Sprint 03.1 and Sprint 04 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden root-task portability and repeated retention, then add deterministic paired comparison of a baseline with one to five identity-based scenarios.

**Architecture:** The root task runner resolves Node from `process.execPath`. Scenario code is isolated under `app/scenarios`: typed contracts describe requests/results, a registry authorizes replacements, a materializer deep-copies and validates models, comparison primitives reuse repeated aggregation, and a sequential coordinator executes each seed across baseline and scenarios. Only scalar snapshots survive ordinary runs; at most baseline and top-ranked-scenario representative results are retained.

**Tech Stack:** Python 3.12, Pydantic 2, SimPy, FastAPI, pytest, JSON Schema 2020-12, Node.js ESM, pnpm, Next.js/TypeScript.
