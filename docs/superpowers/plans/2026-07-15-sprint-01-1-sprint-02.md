# Sprint 01.1 and Sprint 02 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconcile the seeded kernel, then add explicit observation windows, time-weighted metrics, integrity validation, analytical benchmarks, bounded result-detail modes, and measured performance evidence.

**Architecture:** Preserve operational-model `0.2.0`, evolve request/result contracts to `0.3.0`, and keep the simulator responsible only for execution and evidence. Derive windowed metrics from canonical events and lifecycle records, validate that evidence before returning, then apply deterministic result-detail filtering after the run so sampling cannot affect simulation randomness.

**Tech Stack:** Python 3.12, SimPy, Pydantic 2, FastAPI, pytest, JSON Schema 2020-12, standard-library statistics/hash/timing, Node.js, pnpm, Next.js.

**Repository constraint:** Work inline in the existing repository. Do not commit or push.
