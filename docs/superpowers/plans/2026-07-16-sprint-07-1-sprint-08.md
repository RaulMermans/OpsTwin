# Sprint 07.1 and Sprint 08 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Sprint 07 workflow-visualization verification carryover, then deliver deterministic one-factor-at-a-time sensitivity analysis locally across contracts, backend, CLI, Scenario Lab, benchmarks, validation evidence, and documentation.

**Architecture:** Keep workflow hardening in the existing presentation adapter and components. Add sensitivity as a separate `0.6.0` contract and backend package that reuses the scenario override registry, repeated-run aggregation, seed schedule, scalar snapshots, and comparison metric direction/delta semantics. Execute variants sequentially by run index with a shared seed per index; expose the same typed result through FastAPI, CLI, and a compact in-place Scenario Lab panel.

**Tech Stack:** Python 3.12, Pydantic 2, FastAPI, SimPy, pytest, TypeScript, React 19, Next.js, Vitest, HTML/CSS/SVG, pnpm workspace scripts.
