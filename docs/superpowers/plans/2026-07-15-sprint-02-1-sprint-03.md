# Sprint 02.1 and Sprint 03 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace full-event retention in ordinary single runs with compact streaming evidence, then add deterministic sequential repeated-run aggregation with bounded representative evidence.

**Architecture:** Event emission will update a typed audit ledger and observation collector before retaining only events allowed by the requested detail mode. Repeated execution will call this hardened single-run boundary in summary mode, retain typed scalar snapshots, aggregate them with Welford moments and exact bounded scalar series, and rerun one deterministic representative seed with requested evidence.

**Tech Stack:** Python 3.12, SimPy, Pydantic 2, FastAPI, standard-library hashlib/math/statistics/time, pytest, JSON Schema, Node.js/pnpm.
