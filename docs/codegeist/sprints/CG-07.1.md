# Sprint CG-7.1 — Release-blocker closure and feature freeze

Isolated Atlassian track. Does not start CG-8.

## Blockers closed in source

- CSV adapter emits valid `os.1.0.0` snapshots. Completeness stays **partial**. Assumption-based construction is allowed only for `csv-upload` with explicit approved parameters.
- Jira construct re-extracts via the Forge resolver using the reviewed observation window. Browser snapshots are not trusted source evidence. Changed source records return review-required; the reviewed fingerprint is not replaced.
- Signed artifacts bind project, principal, purpose, and type. Reconstruction uses a compact model, not the event history.
- Mapping editor can correct Waiting / Triage / Resolution / Completed / Excluded / Unknown. Template Resolution maps to resolution processing.
- Recurring cash is withheld when modeled processing exceeds staffed paid hours.
