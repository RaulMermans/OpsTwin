## Limitations

- Canonical calibrated `itemCount=1` is a structural placeholder; experiments bind a separate execution volume.
- AI-assisted processing is an effective-mean approximation, not per-case AI execution or mixture tails.
- Hybrid automation only shifts an existing triage completion route; it cannot add stages.
- Historical holdout adequacy does not establish causal validity of an intervention.
- Unapproved calibration correctly refuses construction (`missing_assumptions`). The assumptions checkbox must be set before **Run synthetic calibration**.
