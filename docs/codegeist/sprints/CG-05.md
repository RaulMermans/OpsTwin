## Limitations

- Canonical calibrated `itemCount=1` remains a structural placeholder; experiments bind a separate execution volume.
- AI-assisted processing remains an effective-mean approximation.
- Hybrid automation only shifts an existing triage completion route.
- Interactive replication counts are exploratory.
- Session state is not persisted across Jira refresh.
- Live Jira snapshots stay inside Forge; calibration remotes remain fixture-ID only.
- The default hybrid fixture is structurally valid and exploratory, not historically adequate for OPS.
